# Crumple

**Crumple** is an interactive, hand-drawn landing page for **Yeet Factory**:
fun projects by Rishikesh and Sriram. It is a standalone project. The main
Yeet Factory site, which lists all our projects, lives in a separate repo.

Live at [crumple.yeetfactory.top](https://crumple.yeetfactory.top).

Press the big **YEET** button and the page comes to life. It is a hand-drawn,
scroll-driven 3D scene on a sheet of paper. The letters drop in, a lever gets
pulled, a line runs out to the upcoming projects, the founders sign at the
bottom, and at the end the page crumples up and gets thrown at you.

## Stack

- [TanStack Start](https://tanstack.com/start) (React 19, file-based routing) with server-side rendering
- [Rsbuild](https://rsbuild.dev) as the bundler
- [three.js](https://threejs.org) for the scene, [cannon-es](https://github.com/pmndrs/cannon-es) for the physics
- [Tailwind CSS v4](https://tailwindcss.com) for styling
- Web Audio for the sound effects (they can be turned off from the header)
- Fonts: Old Standard TT and Reenie Beanie, from [Fontsource](https://fontsource.org)

## Getting started

You need [Bun](https://bun.sh).

```bash
bun install
bun run dev        # http://localhost:3000
```

## Building and running in production

```bash
bun run build      # writes dist/client and dist/server
bun run start      # serves the SSR build with srvx
```

## Deployment

The site runs on Cloudflare Pages as the `crumple-landing` project, at
[crumple.yeetfactory.top](https://crumple.yeetfactory.top). Pages builds from
this repo with `bun run build` and serves `dist/client`. Every push to `main`
deploys to production. Other branches get preview deployments.

## Project layout

```
src/
  site.ts            Name, domain and founders. Most of the page copy comes from here.
  routes/            TanStack Router routes (__root.tsx holds the <head> and meta tags)
  components/        DOM layer: Hero, Sections (line, tree, signoff), Finale, Stage
  engine/            The three.js scene: hero lettering, lever, line, ink, paper,
                     notes, crack effect, textures and palette
  lib/               Scroll timeline helpers, shared engine store, sound
public/              Static assets (favicon)
```

The canvas draws the visuals. The DOM sections set the scroll length of each part
and carry screen-reader text, so the page still makes sense without the canvas.

## Customising

Edit `src/site.ts` to change the name, the domain or the people on the page.
Change the meta description in `src/routes/__root.tsx`.

`src/routeTree.gen.ts` is generated by TanStack Router. Don't edit it by hand.
